About Instamrat

Instamrat is a modern quick-commerce platform inspired by Blinkit, designed to deliver groceries, fresh vegetables, snacks, beverages, and daily essentials to customers in just a few minutes. The application focuses on providing a smooth and fast online shopping experience with an attractive and user-friendly interface.

The platform is developed using Angular, HTML, CSS, Bootstrap, and TMDB APIs to create a dynamic and responsive web application. Users can browse products, explore categories, view product details, and enjoy entertainment features like trending movie banners and sliders integrated through TMDB APIs.

Instamrat aims to simplify online shopping by combining technology, convenience, and modern UI design into one powerful delivery application. The project demonstrates responsive web development, API integration, and modern e-commerce functionalities similar to leading quick-delivery platforms.
